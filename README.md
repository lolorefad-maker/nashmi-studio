# Nashmi Studio — منصة SaaS للتصاميم الإعلانية وتحليل الأعمال

منصة لأصحاب الأعمال (شركات، متاجر، صفحات تواصل اجتماعي):

- **استوديو تصميم بالذكاء الاصطناعي** (مثل كانفا): يكتب العميل فكرته، فيكتب النموذج النصوص ويختار الألوان والتنسيق والخط، وتُبنى منه بوستر/إعلان قابل للتعديل بالكامل، ثم يُنزَّل PNG/JPG بجودة كاملة.
  - 6 مقاسات: منشور انستغرام، منشور طولي، ستوري، بوستر A4، إعلان فيسبوك، غلاف.
  - 6 تنسيقات (مركزي، منتج، عرض وخصم، بسيط، مناسبة، قُطري) و7 أنماط ألوان، والتبديل بينها مجاني.
  - محرر بأسلوب كانفا: 28 خطاً (عربي وإنجليزي) مع منتقي خطوط، تأثيرات النص (ظل، رفع، مفرّغ، إطار، نيون، خلفية)، تدرّج الألوان، تباعد الأسطر والحروف.
  - الصور: 10 فلاتر، وتحكم بالإضاءة (السطوع، التباين، التشبّع، الدفء، الحيوية، التمويه)، زوايا دائرية، ظل، استبدال، وتعديل بالذكاء الاصطناعي (إزالة خلفية، إعادة إضاءة...).
  - العناصر: 12 شكلاً، إطارات صور، أكثر من 1500 أيقونة، تنسيقات نصوص جاهزة، رفع صور.
  - أدوات: طبقات (إظهار/قفل/ترتيب)، أدلة محاذاة ذكية، تجميع، نسخ/لصق، الموضع والحجم بالأرقام، تكبير/تصغير، وتنزيل PNG/PNG شفاف/JPG/PDF.
- **لوحة تحليلات بنمط زجاجي (Glassmorphism)**: الإيرادات، الأرباح، متوسط قيمة الطلب، تكلفة اكتساب العميل، العائد على الإعلانات (ROAS)، التحويل، المتابعون، ومؤشر "صحة النشاط".
- **مستشار أعمال AI**: تحليل SWOT، توصيات حسب الأولوية، خطة 30 يوماً، وأفكار محتوى تتحول لتصميم بضغطة.
- **كاتب المحتوى**: 3 صيغ للمنشور + هاشتاغات + نص إعلان ممول لكل منصة.
- **هوية العلامة**: شعار، ألوان، خط، نبرة وجمهور — تُستخدم في كل تصميم وتحليل.
- **حساب خاص لكل عميل** + **لوحة إدارة لك**: كل العملاء وبياناتهم، البحث والفلترة، تغيير الباقات، إضافة نقاط، إيقاف الحسابات، طلبات الترقية، و**تصدير Excel** (العملاء + بيانات أعمالهم + سجل استخدام الذكاء الاصطناعي).
- نظام **نقاط وباقات** (مجاني 30 / احترافي 300 / أعمال 1500): تصميم = 1، نص = 1، صورة = 2، تحليل = 3.
- **عدة علامات تجارية وفريق عمل**: الوكالات تدير أكثر من علامة (كل علامة بهويتها وبياناتها)، ودعوة أعضاء بأدوار (مالك / محرر / مشاهد) عبر رابط دعوة. الحدود حسب الباقة: مجاني 1 علامة · 1 عضو، احترافي 3 · 3، أعمال 15 · 10.
- **مكتبة قوالب**: 24 قالباً جاهزاً لـ 8 مجالات (مطاعم، أزياء، تجميل، عقارات، تعليم، صحة، تجارة إلكترونية، مناسبات منها رمضان والعيد وعيد الاستقلال) — مجانية وتعمل بكل المقاسات.
- **صور بالذكاء الاصطناعي (Nano Banana من Google)** داخل الاستوديو: إدراج صورة أو استخدامها كخلفية، ويمكن وضع صورة المنتج المرفقة داخل مشهد إعلاني. الباقة المجانية: 4 صور شهرياً، والباقات المدفوعة محدودة بالنقاط فقط.
- **مصادر البيانات**: استيراد Excel/CSV (مع قالب جاهز)، وربط متاجر WooCommerce و Shopify مع مزامنة ليلية تلقائية.
- **تقويم المحتوى**: جدولة المنشورات على انستغرام وفيسبوك ونشرها تلقائياً عبر Meta. بدون ربط، يتحول المنشور في موعده إلى "جاهز للنشر" مع الصورة والنص.
- **التقرير الشهري**: صفحة تقرير A4 جاهزة للطباعة/PDF، ومشاركة الملخص عبر واتساب، وإرسال تلقائي أول كل شهر بالبريد وواتساب.
- **مساعد الأعمال الذكي**: محادثة يعرف فيها المساعد بيانات النشاط ومؤشراته وأنظمته، يحلل أي مشكلة ويقترح حلولاً، ويقرأ الصور وملفات PDF و Excel. عند الطلب يصمّم:
  - **أنظمة** (مخزون، عملاء CRM، فواتير، موظفين، حجوزات... ERP مصغّر) تُنشأ بضغطة كجداول حقيقية مع إضافة/تعديل/بحث/تصدير Excel.
  - **أتمتة** (جدولة يومية/أسبوعية/شهرية، أو عند إضافة سجل) بخطوات: تحليل AI، تنبيه داخل المنصة، بريد، واتساب، إضافة سجل، webhook.
  - **إضافة بيانات** إلى الأنظمة من المحادثة أو من ملف مرفق.
  يعمل بنموذج نشمي إذا ضُبط `AI_BASE_URL`، وإلا بـ Gemini (`GEMINI_TEXT_MODEL`، مع انتقال تلقائي لنموذج بديل عند الضغط). كل رسالة = نقطة.
- **واجهة عربية وإنجليزية**: زر تبديل اللغة في كل الصفحات، مع قلب الاتجاه تلقائياً (RTL / LTR).

## التشغيل

يتطلب Node.js 22.13 أو أحدث (قاعدة البيانات SQLite مدمجة في Node، بدون تثبيت إضافي).

```bash
npm install
npm start
```

ثم افتح http://localhost:3000

| الحساب | البريد | كلمة المرور |
|---|---|---|
| مدير المنصة (أنت) | `ADMIN_EMAIL` في ملف `.env` | `ADMIN_PASSWORD` في ملف `.env` |
| عميل تجريبي | `demo@nashmi.studio` | `demo12345` |

## ربط نموذج Nashmi

مفتاح الـ API محفوظ في ملف `.env` (`AI_API_KEY`) ويبقى على الخادم فقط ولا يصل للمتصفح.
ينقص فقط **رابط الـ API**: ضعه في `AI_BASE_URL` ثم أعد تشغيل الخادم:

```env
AI_BASE_URL=https://your-nashmi-endpoint/v1
AI_MODEL=nashmi
```

الكود يرسل طلبات بصيغة OpenAI (`POST {AI_BASE_URL}/chat/completions`). إذا كانت صيغة Nashmi مختلفة، عدّل دالة `chatJSON` فقط في [server/ai.js](server/ai.js).
قبل الربط تعمل المنصة بـ **وضع تجريبي** (مولّد داخلي)، ويظهر ذلك بنقطة صفراء بجانب النقاط في الشريط العلوي.

## هيكل المشروع

```
server/
  index.js          الخادم (Express) والملفات الثابتة
  db.js             قاعدة البيانات SQLite + الجداول + الحسابات الأولية
  auth.js           الجلسات (JWT في كوكي httpOnly) والصلاحيات
  ai.js             الاتصال بالنموذج + المولّد الاحتياطي
  analytics.js      حساب مؤشرات الأداء
  excel.js          تصدير Excel (من اليمين لليسار)
  routes/           auth · client · admin
public/
  index.html        الصفحة التعريفية
  login.html        الدخول / إنشاء حساب
  app.html          لوحة التحكم (عميل + إدارة)
  css/              نظام التصميم الزجاجي + الاستوديو
  js/poster.js      محرك تنسيق التصاميم (Fabric.js)

data/app.db         قاعدة البيانات (تُنشأ تلقائياً — خذ نسخة احتياطية منها)
```

## تفعيل المزايا الخارجية (في ملف `.env`)

كل ميزة تعمل بدون هذه الإعدادات بوضع بديل، وتصبح تلقائية بعد إضافتها:

| الميزة | الإعدادات | بدونها |
|---|---|---|
| صور الذكاء الاصطناعي (Nano Banana) | `GEMINI_API_KEY` من aistudio.google.com، و`GEMINI_IMAGE_MODEL` (الافتراضي `gemini-2.5-flash-image`). **يلزم تفعيل الدفع على مشروع Google** — نماذج الصور ليس لها حصة مجانية | تُنشأ صورة فنية بألوان العلامة |
| النشر التلقائي على انستغرام وفيسبوك | `META_APP_ID`، `META_APP_SECRET`، `PUBLIC_URL` (رابط https عام) | المنشور يظهر "جاهز للنشر يدوياً" في موعده |
| البريد (الدعوات والتقرير الشهري) | `SMTP_HOST`، `SMTP_PORT`، `SMTP_USER`، `SMTP_PASS`، `MAIL_FROM` | رابط الدعوة يُنسخ يدوياً، والتقرير يُطبع أو يُشارك |
| واتساب (ملخص التقرير) | `WA_TOKEN`، `WA_PHONE_ID`، `WA_TEMPLATE` (قالب معتمد فيه متغير {{1}}) | زر "مشاركة عبر واتساب" يعمل دائماً |

**تطبيق Meta**: من developers.facebook.com أنشئ تطبيقاً من نوع Business، أضف Facebook Login، وضع رابط الرجوع `PUBLIC_URL/api/social/callback`، واطلب الصلاحيات: `pages_show_list`، `pages_manage_posts`، `instagram_basic`، `instagram_content_publish`. انستغرام يحتاج حساب أعمال مرتبطاً بصفحة فيسبوك.
